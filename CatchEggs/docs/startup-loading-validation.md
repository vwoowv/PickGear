# 초기 로딩 개선 및 검증

검증일: 2026-09-16 / Cocos Creator 3.8.6.

## 변경한 동작

- 시작 시 모드 선택 UI를 표시하고 `GAME_READY`를 보낸다. 이 시점에는 게임용 BGM, 캐릭터, 프리팹, MIDI JSON 로드를 기다리지 않는다.
- 모드 선택 시 선택한 배경·BGM·레벨별 캐릭터와 공통 프리팹을 병렬로 준비한다. 효과음은 기존 씬 참조로 준비된다.
- 기존 로딩 UI에 진행률을 표시하고 입력을 차단한다. 오디오 플레이어와 준비 화면 초기화가 끝날 때까지 시작 버튼 실행도 막는다.
- 필수 배경/BGM 준비 실패 시 오류를 기록하고 선택 화면으로 복귀한다. 기존 프리로드의 선택적 리소스 실패는 경로와 오류를 기록한 뒤 계속 진행한다.
- 타이틀 복귀·종료·다른 모드 준비·컴포넌트 파괴 후 완료된 이전 요청은 현재 화면/진행률을 변경하지 않는다.
- BGM은 192kbps MP3로 교체했다. 확장자 없는 런타임 경로와 기존 UUID는 유지했다. 씬/프리팹 및 직렬화 필드 이름·타입은 변경하지 않았다.

## 음원 크기 및 무결성

| 파일 이름 | 이전 WAV (bytes) | 변경 MP3 (bytes) | 디코딩 재생시간 |
| --- | ---: | ---: | ---: |
| Sanrio1_Full_Version | 15,636,202 | 1,297,196 | 54.0초 |
| Sanrio2_Full_Version | 16,504,770 | 1,369,196 | 57.0초 |
| Sanrio3_Full_Version | 23,778,798 | 1,972,268 | 82.124125초 |

합계 55,919,770 → 4,638,660 bytes (약 53.33 → 4.42 MiB, 91.7% 감소).
각 음원을 같은 PCM 형식으로 디코딩해 원본과 샘플 수가 동일함을 확인했다.
일정 간격으로 추출한 샘플의 파형 상관계수는 각각 0.999939 / 0.999341 / 0.998341이었다.
이는 자동 무결성 점검이며 청음에 의한 음질 평가를 대체하지 않는다.
Creator가 기존 UUID로 MP3를 재import한 것도 확인했다.

## 자동 검증

`tests/startup-loading.test.cjs`는 실제 TypeScript 컴포넌트를 Creator에 포함된 TypeScript로 변환하고,
엔진/리소스 경계만 대체하여 비동기 로딩과 상태 전환을 확인한다. 별도 npm 패키지를 프로젝트에 추가하지 않았다.
Creator 설치의 `app.asar.unpacked/node_modules` 디렉터리를 `NODE_PATH`로 지정하여 실행한다.

```sh
NODE_PATH="<Creator 설치 내 app.asar.unpacked/node_modules 경로>" node --test tests/startup-loading.test.cjs
```

6개 시나리오 통과:

1. 게임 리소스 요청 없이 모드 선택과 `GAME_READY`에 도달.
2. 선택한 모드만 요청하고 BGM 및 플레이어 준비 전에 게임 시작을 차단.
3. BGM 실패 시 선택 화면으로 복귀하고 재선택 성공.
4. 로딩 중 타이틀 복귀 후 이전 로드 완료가 준비 화면을 다시 열지 않음.
5. 이전 모드의 늦은 완료가 새 모드의 로딩 화면을 숨기지 않음.
6. 선택적 효과 프리로드 실패는 경고를 기록하고 준비 완료까지 진행.

수정한 컴포넌트와 의존 코드의 TypeScript 검사도 통과했다 (`noEmit`, 엔진 선언은 `skipLibCheck`).
프로젝트 전체 TypeScript 검사에는 변경 전부터 있던 `midiJson.ts`의 isolatedModules 오류와
`extensions/displayFBX`의 타입 오류 등이 있어 전체 통과로 간주하지 않는다.

## 실제 Preview 확인

Creator 3.8.6에서 프로젝트를 열고 재import 후 `main.scene`의 브라우저 Preview로 확인했다.
세 모드 모두 선택→준비→게임 시작→결과 화면까지 확인했다.
모드별 배경·캐릭터와 각 MP3의 BGM STARTED 이벤트도 확인했다.
Preview에서 누락 에셋·직렬화·컴파일 오류는 발생하지 않았다.
기존 스폰 간격 재시도 경고는 나타났으며 이번 변경 범위에는 포함하지 않았다.
Editor 시작 로그에는 기존 displayFBX 플러그인 이름의 대문자 관련 설정 오류 메시지가 있다.

## 측정 범위

음원 용량 감소율은 로딩 시간 감소율이 아니다. 배포 서버, 모바일 실기기, 캐시가 없는 네트워크 환경의
접속→모드 선택 및 선택→게임 시작 시간은 별도로 측정해야 한다.
엔진·씬의 초기 로딩은 여전히 필요하다. 씬의 직접 참조 이미지와 첫 화면 이미지 최적화는 이번 변경에 포함하지 않았다.
플랫폼/빌드 설정은 바꾸지 않았고 재빌드·배포는 수행하지 않았다.
